## 🗺️ Project structure (what lives where)

```
design-system/
├── tokens/
│   ├── figma-raw/*.json     ← manual Figma snapshots (MCP get_variable_defs) — ONLY entry point for design values
│   └── tokens.json           ← generated by scripts/build-source-tokens.ts — never hand-edit
├── dist/                     ← GENERATED output — never hand-edit, never commit changes manually
│   ├── css/variables.css     ← --color-* / --spacing-* CSS custom properties
│   └── json/                 ← tailwind-tokens.json, flat tokens.json
├── src/components/           ← component layer (*.tsx) + typography.ts + icons.tsx
├── stories/                  ← one *.stories.tsx per component (visual QA tool)
├── .storybook/preview.ts     ← loads variables.css + Tailwind base; Direction toolbar decorator
├── scripts/*.ts              ← token build scripts (run via tsx)
├── style-dictionary.config.ts
└── tailwind.config.ts        ← consumes dist/json/tailwind-tokens.json (satisfies Config)
```

**Golden rule:** `Figma → tokens/figma-raw/ → npm run tokens:sync → dist/ → components`. Values flow one way. Anything else is a finding.

## 🧱 Expected code structure

**Components (`src/components/<Name>.tsx`)**
1. Imports (react types via `import type`, radix-ui, `fontStyle`/`fontStack` from typography.ts)
2. `const SIZES = {…} as const` — size map; unions derived: `type Size = keyof typeof SIZES`
3. Variant maps typed with a single `interface VariantStyle` (optional fields for state-specific entries), composed from shared consts — NOT `Record<>` annotations (they reintroduce `undefined` under `noUncheckedIndexedAccess`)
4. Local subcomponents/icon JSX (stroke via `currentColor`)
5. Exported main function — props interface exported (`NameProps`); native forwarding via `Omit<ComponentPropsWithoutRef<"button">, …>` intersection; **`{...rest}` spread FIRST**, computed style/handlers after, consumer handlers *composed* with internal ones and `...consumerStyle` merged last

**Stories (`stories/<Name>.stories.tsx`)**
- `default` export with `title: "Components/<Name>"`
- `Playground` — args typed against the component's exported props type; argTypes options reuse exported unions/arrays
- All-variants matrix mirroring the Figma component set (every hierarchy × size × state)
- Transient states simulated via a `forceState`-style prop — labeled-only columns are findings

**Every new component MUST have**: a story file, an entry in the matrix, verified token vars. Nothing ships without its story.

## 🔍 Review process

### Pass 1 — Understand before judging
1. Get the changes (`gh pr view/diff`, `git diff <base>...HEAD`, `git show`, or plain `git diff`).
2. Read the **full content** of every changed file — hunks alone are forbidden.
3. Anchor against exemplars: components ↔ `src/components/Button.tsx` / `Checkbox.tsx`, stories ↔ `stories/Button.stories.tsx`.
4. Write one sentence stating the change's *intent*; judge the diff against it.

### Pass 2 — Role-by-role checklist

**🎨 Token Architect**
- Every hex in `src/**` must map to an existing var in `dist/css/variables.css`. Grep each referenced `--color-*` and confirm it exists (undefined vars fail silently).
- New raw values with no token → request `npm run tokens:sync` or prove Figma-exactness (focus-ring spreads are acceptable literals).
- `dist/**` or `tokens/tokens.json` hand-edited? Blocker.

**⚛️ React Engineer**
- Enumerate the FULL variant matrix (size × hierarchy × checked/hover/focused/disabled) and trace every map lookup — past real bug: missing `UNCHECKED.tint` crashed render.
- Controlled AND uncontrolled modes work; callbacks resolve to functions actually in scope (past real bug: undefined setter in a story).
- Hook rules, stale closures, list keys.
- `{...rest}` discipline: spread goes FIRST on the element; internal handlers compose with consumer handlers (call `consumerHandler?.(e)` inside); `style={{ ...computed, ...consumerStyle }}`. A bare trailing `{...rest}` that clobbers internals is a finding.

**🧝 TypeScript Engineer — reduce types**
The bar: types must catch bugs or document intent. Anything else is ceremony. Flag:
- **Redundant annotations** — variables/returns the compiler already infers (`const x: string = "medium"`).
- **Hand-written unions duplicating data** — if a literal array/map exists, the union MUST be derived (`keyof typeof SIZES`, `(typeof ARR)[number]`). Two sources of truth = finding.
- **Ceremony interfaces** — `INameProps`, extending native element props without forwarding need, one-use type aliases, generic components without a caller-controlled type.
- **Banned**: `enum`s (use `as const`), `any` (use `unknown` + narrow at boundary), non-null `!` without a one-sentence justification, `@ts-ignore` (only `@ts-expect-error` with description).
- **Boundary casts**: JSON imports don't produce tuples — ONE documented cast at the boundary (see typography.ts `token()`) is correct; scattered casts of the same value are not.
- **`satisfies` over annotation** when narrow literal types matter (variant maps, config objects).
- **Over-typing ratio**: if added type-code exceeds ~30% of runtime-code lines in the diff, call it out — same behavior, less ceremony.
- **Prop-forwarding correctness** when intersecting with native props: watch for key collisions producing `never` (e.g. our `type` prop vs button's `type` — must be Omitted), and for `Record<K,V>` indexed by union keys gaining `| undefined` under `noUncheckedIndexedAccess` (prefer explicit-key object literals + shared const composition).

**🧩 Radix & A11y Specialist**
- Radix primitives from monolithic `radix-ui` used unstyled — verify exports exist: `node -e "const r=require('radix-ui'); console.log(!!r.Checkbox)"`.
- Keyboard operable; focus ring behavior noted; disabled semantics; label association; `aria-hidden` on decorative icons.

**📖 Storybook QA Lead**
- Story exists, Playground has argTypes, matrix mirrors Figma set completely.
- Hover/focused columns genuinely simulate states, not just labels.
- Mentally click through interactive stories — every callback must be reachable and defined.

**🔒 Repo Guardian**
- No secrets in diffs, fixtures, remotes (warn loudly). No comments unless asked. No unjustified deps. No committed build output (`storybook-static/`, caches). New source files are `.ts/.tsx` only — a new `.jsx/.js` under src/stories/scripts is a blocker.

### Pass 3 — Verify, then report
```bash
npm run typecheck                                   # MUST pass — blocker if not
npx esbuild <changed .tsx files> --outdir=/tmp/review-check   # TS reads natively, no loader flag needed
grep -o "\-\-color-[a-z0-9.-]*" <changed files>     # confirm each exists in dist/css/variables.css
npm run tokens:build                                # only if tokens/ changed
```
Unverified claims must be tagged `(suspected)` — never stated as certain.

## 📊 Severity rubric

| Severity | Meaning |
|---|---|
| `blocker` | Crashes, pipeline violation, secret exposure, typecheck failure, new `.jsx` source |
| `major` | Wrong behavior users will hit; missing required variants/story coverage; a11y failure; API narrowing (dropped prop forwarding) |
| `minor` | Convention drift; misleading QA artifacts; fragile patterns; type ceremony that hurts readability |
| `nit` | Redundant annotation; style preference — only when clearly violating established convention |
